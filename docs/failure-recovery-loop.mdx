# Failure Recovery Loop

## Problem

Recover from failure without manual intervention.

---

## Ved Approach

_Model recovery as convergence._

---

## Implementation

```
domain Service {
    state {
        running: bool
    }

    goal running == true

    transition restart {
        step {
            if !running {
                running = start_service()
            }
        }
    }
}
```

---

## Behavior

- Service automatically restarts
- System stabilizes

---

## Summary

Recovery becomes:

> continuous stabilization
