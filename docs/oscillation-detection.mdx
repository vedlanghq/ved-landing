# Oscillation Detection

## Problem

System repeatedly changes state without stabilizing.

---

## Ved Approach

_Detect unstable convergence._

---

## Example Scenario

```
transition flip {
    step {
        flag = !flag
    }
}
```

---

## Behavior

- State never stabilizes
- runtime detects oscillation

---

## Outcome

- warning generated
- system flagged unstable

---

## Summary

Ved can detect:

> non-converging system behavior
